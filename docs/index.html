About Happwner Web

A fully client-side port of Happwner — the Android app & Xposed module that extracts clean VPN configurations from the Happ proxy client. This web version keeps the crypto and conversion engine and drops the Android-only parts (Xposed hooks, the local bridge service, intent handling).

What works here

  • Link decryption — happ://crypt … happ://crypt5 (RSA + ChaCha20-Poly1305, legacy & salted layouts), v2raytun://crypt/ (RSA-4096), plus happ://add/, v2raytun://import/ and incy:// unwrapping, incl. links wrapped in http(s) URLs.
  • Encrypted subscription profiles — AES-128-GCM bodies signed with the Encrypt-Tag header and the ten keys built into Happ (key01 … key10).
  • HWID field — generate random hardware IDs to send as x-hwid when fetching subscriptions.
  • Converter — Base64 ↔ links, JSON outbounds → proxy links (vless/vmess/ss/trojan/hysteria2/tuic), full Xray → sing-box config conversion and merging.
  • Server overview — decrypted output is parsed into server cards so you can see hosts, ports, security and transport at a glance.
  • Batch mode — one link per line.

Not available in a browser

  • Xposed features (link interception, HWID spoofing inside Happ, profile unlocking, gestures) — they hook other apps at the OS level.
  • The local "bridge" HTTP service on port 8166 that feeds updated subscriptions to other VPN apps.

Privacy

Decryption happens entirely in your browser — links, keys and configs are never uploaded anywhere. The optional subscription fetcher is the only network feature; with the CORS proxies it routes the request through a third-party relay, so for sensitive subscriptions prefer the manual paste mode.
